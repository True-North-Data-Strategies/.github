# Reporting a security concern

Please email [jacob@truenorthstrategyops.com](mailto:jacob@truenorthstrategyops.com) with the repository name, affected version, a short description and a safe reproduction using fictional data.

Do not put credentials, client records or a working exploit against a live system in a public issue or pull request. If evidence is sensitive, describe the type of evidence first and ask for a suitable private transfer method. Never email a live secret.

If a credential is exposed, its owner should revoke or rotate it through the issuing service. Removing a file does not revoke a credential or remove repository history.

Support and update commitments follow the relevant repository's release policy or service agreement. This default does not expand authorization to test client systems.
